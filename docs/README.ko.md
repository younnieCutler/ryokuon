# Ryokuon

**회의 기록을 내 Mac 안에.** 통화 녹음, 전사, 검색, 메모, 내보내기를 제공하는 macOS 앱입니다. 계정이나 구독이 필요하지 않습니다.

Apple silicon(애플 실리콘) / macOS 26 이상. 한국어·일본어·영어 지원. 음성과 전사 내용을 업로드하지 않습니다. 음성 인식 모델 다운로드와 수동 업데이트 확인에는 인터넷을 사용합니다.

현재 제품 출시 준비 단계입니다. Developer ID(개발자 배포 인증) 서명, notarization(Apple 공증), 실제 기기 검증을 완료한 배포물이 필요합니다. 기존 0.1.x 배포물에 이 보증이 소급 적용되지는 않습니다. [전체 안내·소스 빌드](../README.md).

## 사용하기

1. 라이브러리를 엽니다. 녹음 권한 없이도 파일 가져오기와 재생은 가능합니다.
2. ‘녹음 권한 설정’에서 마이크·앱 소리·저장 폴더 접근을 허용합니다. 녹음 전에 참석자에게 알리고 동의를 확인하세요.
3. 소리를 재생하는 통화 앱을 선택하고 녹음을 시작합니다. 헤드셋은 내 목소리와 상대방 소리를 분리하는 데 도움이 됩니다.
4. 중요한 순간에 책갈피를 추가합니다. 종료 후 자동 전사가 시작되며, 설정에서 자동 처리를 끌 수 있습니다.
5. 저장된 음원을 선택해 전사 문장이나 책갈피 위치부터 재생합니다. 회의 메모를 작성하고 MP3 / Markdown(텍스트 문서 형식)으로 내보냅니다.

전체 회의를 검색할 수 있습니다. 검색어 여러 개를 입력하면 같은 회의에 모든 검색어가 포함된 결과를 찾습니다. 메모·앱 이름·책갈피도 검색합니다.

`⌘I`: 가져오기 / `⇧⌘B`: 녹음 중 책갈피 / `⇧⌘N`: 선택한 회의 메모.

내장 마이크는 mono(단일 음성 채널)로 저장되어 화자를 분리하지 못합니다. 외부 마이크를 사용해도 상대방 채널의 여러 사람을 구분하는 기능은 없습니다. 언어 자동 감지는 녹음 전체에 하나의 언어를 선택하므로 혼합 언어 통화는 수동 확인이 필요합니다.

기본 저장 위치는 `~/Documents/ryokuon`이며 설정에서 변경할 수 있습니다. Finder(파일 관리 앱)에서 하위 폴더로 정리해도 됩니다. 녹음 삭제는 영구 삭제이므로 중요한 데이터는 백업하세요. [개인정보 안내](../PRIVACY.md).
