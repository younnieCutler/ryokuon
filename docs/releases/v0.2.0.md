# Ryokuon 0.2.0

Release candidate. No public, notarized 0.2.0 binary has been published yet.

## Changes

- Search meeting titles, applications, transcripts, notes and bookmarks together.
- Add time-stamped bookmarks and meeting notes. Export notes and bookmarks to Markdown even without transcription.
- Keep transcription jobs across restarts and preserve selection through lossless audio conversion.
- Stream long recordings for playback and transcription instead of loading their full PCM audio into memory.
- Stop and preserve capture on write failures, buffer overflow, low disk space and forced sleep. Recover complete WAV frames without overwriting existing files or following symlinks.
- Isolate stopped-capture recovery from concurrent imports and prevent concurrent writer processes.
- Improve EN/JA/KO onboarding, recording consent, keyboard actions and small-window controls.
- Verify update hashes, publisher signatures and notarization; preserve installation rollback.
- Bundle a pinned static MP3 encoder with its license, source and build recipe.

## Compatibility

Apple silicon and macOS 26 or newer. Existing session metadata remains readable; new notes, bookmarks and transcription state use additional metadata fields. Installed speech models process recordings locally. Built-in microphone capture uses mono; separate channels do not provide multi-person speaker diarization.

## Validation and publication

The application changes passed 77 tests across 26 suites on macOS, release-build and development-signature checks, CLI checks, and actual-app visual/export regression checks. This is not hardware acceptance or proof of notarization. Verify the versioned candidate's CI before signing.

Complete [the production release checklist](../RELEASE.md), including measured call-app, Bluetooth and long-recording checks. On an Apple silicon Mac with a Developer ID Application certificate, configured Keychain notary profile and authenticated GitHub CLI:

```bash
export RYOKUON_SIGN_IDENTITY='Developer ID Application: your publisher (TEAMID)'
export RYOKUON_NOTARY_PROFILE='your-keychain-profile'
bash Scripts/make_release.sh --publish
```

The command creates a draft GitHub release with the notarized ZIP, DMG and checksums. Use these notes as the release description, include the verified publisher Team ID, validate a browser-downloaded install on a clean Mac, then publish the draft. Ad-hoc CI artifacts must not replace production release assets.
