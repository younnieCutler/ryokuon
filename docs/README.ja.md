# Ryokuon

**会議の記録を、この Mac に。** 通話の録音、文字起こし、検索、メモ、書き出しを行うネイティブアプリです。アカウントやサブスクリプションは不要です。

Apple シリコン / macOS 26 以降。日本語・韓国語・英語に対応。音声と文字起こしはアップロードしません。音声認識モデルの取得と手動の更新確認にはインターネットを使います。

現在は製品リリースの準備段階です。Developer ID 署名、Apple の公証、実機受け入れ検証を終えた配布物を公開する必要があります。既存の 0.1.x 配布物にこの保証が追加されるわけではありません。[詳細とソースからのビルド](../README.md)。

## 使い方

1. ライブラリを開きます。録音権限がなくても読み込みと再生は利用できます。
2. 「録音の権限を設定」でマイク、アプリ音声、保存先へのアクセスを許可します。録音前に参加者へ知らせ、同意を確認してください。
3. 音を再生している通話アプリを選び、録音を開始します。ヘッドセットを使うと自分と相手を分けやすくなります。
4. 重要な箇所にブックマークを追加。終了すると文字起こしが始まります。自動処理は設定でオフにできます。
5. 保存された音声を選択し、文字起こしの行やブックマークから再生します。会議メモと一緒に MP3 / Markdown を書き出せます。

全会議を検索できます。複数の語を入力すると、同じ会議にすべての語が含まれるものに絞ります。メモ、アプリ名、ブックマークも検索対象です。

`⌘I`: 読み込み / `⇧⌘B`: 録音中のブックマーク / `⇧⌘N`: 選択した会議のメモ。

内蔵マイクではモノラルとなり、話者の分離はできません。外部マイクでも相手側の複数人を識別する機能はありません。言語自動判定は録音全体に一つの言語を選びます。混在する言語は手動確認が必要です。

保存先は `~/Documents/ryokuon`。設定で変更でき、Finder で下位フォルダに整理できます。録音削除は永久削除です。重要なデータはバックアップしてください。[プライバシー](../PRIVACY.md)。
